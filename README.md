# Bo Repo

Tijdelijke webpagina voor [borepo.be](https://borepo.be) in afwachting van de volwaardige website, die in februari 2027 verschijnt.

Selien van Bo Repo maakt urnes voor overleden mensen en dieren, afgestemd op de eigenschappen en kenmerken van de overledene. Tot de nieuwe website online staat, verwijst de pagina door naar [Instagram](https://www.instagram.com/bo_repo/) en naar [selien@borepo.be](mailto:selien@borepo.be).
