# Bo Repo

## Doel

Tijdelijke webpagina voor borepo.be in afwachting van een volwaardige website.

## Beschrijving

Selien van Bo Repo maakt urnes voor overleden mens of dier.
De urnes worden gemaakt volgens de eigenschappen en kenmerken van de overledene.

## Tekst

Er wordt noestig gekneed aan de website van Bo Repo!
Deze zal in februari 2027 verschijnen.
Tot dan is het grootste deel van de prototypes en de reeds gematchte urnen te bekijken 
op instagram.com/bo_repo, samen met het huidige reilen en zeilen.
Voor verdere vrijblijvende informatie kan je ook per mail terecht: selien@borepo.be

## Huisstijl

- Modern en clean ontwerp
- Kleur RGB: 98 146 110
- Font beschikbaar in map fonts (woff2, woff, otf): ITC Garamond Book Narrow Regular

## Technisch

- Responsieve webpagina
- Mobile first aanpak
- CSS-bestanden in de map css
- Kleuren in css-variabelen
- Font in rem eenheid
- Live Server extensie in VS Code voor previews
